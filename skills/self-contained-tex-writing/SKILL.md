# TeX 文書内で説明を完結させる

TeX の記述は、想定する読者が、その文書の本文・数式・文書内参照を通して内容を理解できる形で完結させる。
Lean との対応情報や外部資料への参照は、本文にそろえた説明を補う役割として扱う。

## 適用範囲

TeX で書く計算資料、数学・物理の解説、論文、Blueprint の本文を作成・修正・レビューする場合に適用する。
主本文の説明は、章・付録や `\input`・`\include` で組み込む内容を含む生成文書で確認する。
基礎事項の詳細証明は、主本文から明示的に参照する独立した TeX の補助資料にまとめる。主本文には、使用する結果、その成立条件、今回の対象への適用理由をそろえる。
複数の `.tex` ファイルや共通スタイルを使う構成にも適用する。

## 本文にそろえる内容

文書の目的と想定する読者の予備知識を定め、扱う結果について次の内容を記述する。

1. **対象と定義。** 扱う問題、模型、量、記号を定義し、数式中の各対象の意味を示す。
2. **仮定と適用範囲。** パラメータの範囲、定義域、境界条件、規格化、単位や符号の規約など、主張の成立に必要な条件を明示する。模型の仮定と、そこから導く性質を区別する。
3. **導出・証明。** 出発式、使う関係、主要な変形、結論へのつながりを、文章と数式で追える形にする。場合分け、極限、近似を使う箇所では、その条件と正当化を示す。
4. **結論と解釈。** 得られた結果、成立条件、数学的・物理的な意味を明示する。厳密な結果と近似による結果を区別し、近似では採用した精度や有効範囲を示す。

説明の詳しさは、読者の予備知識と文書の目的に合わせる。文書固有の定義・仮定と、結論を支える論理のつながりは本文にそろえる。

## 主本文と基礎事項の補助資料

主本文は、読者の問い、成立条件、主な結論、主要な導出、解釈を見渡せる構成にする。各節がどの結論を支えるかを明示し、証明の依存順とは別に説明の順序を決める。

ここで基礎事項とは、文書の主題となる結果を支える、共通の数学的性質や前提の基礎付けをいう。その詳細証明は、主本文とは別のソースファイルと生成文書を持つ補助資料にまとめる。例えば、状態空間の射影・ノルムの一般的性質、自己共役性や逆作用素の存在を支える証明が該当する。主本文からは、必要な定理・節へ直接到達できる参照を付す。

主本文には、その模型や問題に固有の結論を理解するための導出を記述する。基礎事項を参照する箇所では、使う主張と仮定を示し、対象が仮定を満たす理由から導出を続ける。模型固有の長い計算は、主本文の流れに応じて同じ文書の付録へ配置できる。

配置は次の三点を別々に判断して決める。

- **証明の必要性。** 主張を裏付けるために、何をどこまで証明する必要があるか。
- **一般性の必要性。** 対象の結論に必要な対象・パラメータ・場合分けの範囲は何か。
- **本文での詳しさ。** 読者が問いから結論までを追うために、どの導出をその場で読む必要があるか。

Lean の宣言名、全域除算などの実装規約、形式化のための一般化は、読者向けの数学的な主張と役割を分け、必要な詳細を補助資料に配置する。主本文には、非零条件など結論の成立に必要な数学的条件を記述する。証明範囲と Lean・TeX の仮定・結論の対応は、配置先を含めて保持する。

## 文書内参照と文献

既出の定義・式・定理は、文書内の節・式番号・定理番号を使って参照する。
模型固有の長い計算は同じ文書の付録などに配置し、基礎事項の詳細証明は独立した補助資料へ参照を接続する。
参照先は、読者が必要とする主張や導出に直接到達できる単位で指定する。

既知の定理や文献の結果を使う場合は、必要な主張と適用条件を本文に示し、現在の対象がその条件を満たす理由を説明する。出典は通常の文献引用で示す。
文献由来の既知の結果と、この文書で導出する結果を区別し、後者の計算・証明は主本文・付録または明示した基礎事項の補助資料にそろえる。

## Lean や作業記録との役割分担

Lean の定義・定理・証明に対応する内容を、TeX では数学上の対象・仮定・命題・導出として記述する。
Lean の宣言名やソースへのリンク、形式化の進捗は、本文の数学的説明と役割を区別して添える。

説明に必要な内容が Lean ソース、Markdown の作業記録、PR、会話、TeX のコメントにある場合は、その内容を役割に応じて TeX の主本文・付録・基礎事項の補助資料に反映する。
読者向けの定義や証明は、生成される文書に表示される位置に置く。
作業経緯や実装上の調整は、それぞれの作業記録で管理する。

Lean と TeX の仮定・結論・対応情報を変更したときは、プロジェクトの対応管理規則に従って両者を照合する。
このスキルは、TeX の説明の完結性を担当する。

## 作成・修正の手順

1. 文書の入口から対象の節までを読み、問い・主な結論・主要な導出のつながりを整理する。使う定義・仮定・先行結果と、その記載箇所を確認する。
2. 主張ごとに出発点から結論までをたどり、説明を補う箇所を特定する。
3. 主本文・付録・基礎事項の補助資料の役割を決め、必要な定義、式変形、正当化、解釈を配置して参照を接続する。
4. Lean や外部の作業記録から得た内容を、読者に伝わる数学的な説明へ書き直す。
5. プロジェクトの方法で生成文書を確認し、読解に必要な内容と参照が表示されることを確かめる。

草稿では、記述済みの範囲と、説明・導出を補う箇所を区別する。完了を報告するときは、その範囲と実際に確認した内容を示す。

## 確認基準

対象範囲を TeX から生成した主本文と補助資料として読み、次を確認する。

- 冒頭で問い・主な結論・成立条件が分かり、各節の役割がその結論につながっている。
- 基礎事項の詳細証明を含める場合は、独立した補助資料にまとまり、主本文から必要な結果へ直接到達できる。
- 補助資料の詳細証明を読み飛ばしても、主本文の仮定・主要な導出・結論を追える。
- 記号・対象・仮定・成立条件を、主本文と明示した参照から特定できる。
- 出発式から結論までの主要な導出を、文章と数式で追える。
- 既知の結果を使う箇所では、その主張・適用条件・今回の対象との対応が分かる。
- Lean との対応情報や作業記録へのリンクは、本文にそろえた説明を補う情報として配置されている。
- 章・式・定理・付録・補助資料への参照が、必要な記述につながっている。
